# Money Manager - Frontend

A React-based frontend application for managing income and expenses.

## Features
- Add income and expense transactions
- Account transfer between Cash and Bank
- Analytics (weekly, monthly, yearly)
- Filter transactions by date, category, and division

## Tech Stack
- React (Vite)
- Tailwind CSS
- Axios

## Live URL
https://money-manager-frontend-chi.vercel.app/


## Backend Repository
This project uses a separate backend service for handling APIs and database operations.

Backend GitHub Repository:
https://github.com/Mathanraj-d12/money-manager-backend

## Backend Live URL
https://money-manager-backend-794s.onrender.com

## Architecture
This project follows a **separated frontend and backend architecture**:
- Frontend is built using React and deployed on Vercel
- Backend is built using Node.js and deployed on Render
- Frontend communicates with backend via REST APIs
